# AsyncAPI Sub-Flow

Index of the AsyncAPI format sub-flow run by the contracts build prompt. Read exactly one file per invocation — the format sub-prompt selects the intent.

| File | Read when |
| --- | --- |
| [author.md](author.md) | Authoring or extending the AsyncAPI document from a Emery change. |
| [importer.md](importer.md) | Normalising an operator-supplied external AsyncAPI document onto Emery conventions. |
| [verifier.md](verifier.md) | Verifying an existing AsyncAPI artefact (read-only; renders a validation report). |
