# Vectis runtime schemas

JSON Schemas (draft 2020-12) for the artifacts the Vectis target consumes and emits. Schemas are owned by the Vectis WASI tool that runs them; the bodies are embedded in the tool (under the extension crate's `schemas/`), not committed in the adapter tree. Canonical `$id` URLs:

- [`composition.schema.json`](https://schemas.specify.dev/vectis/composition.schema.json) — JSON Schema for `composition.yaml`. Regenerated by the Vectis target's [`build` brief](../briefs/build.md); validated by `specify extension run vectis -- validate composition`.
- [`tokens.schema.json`](https://schemas.specify.dev/vectis/tokens.schema.json) — JSON Schema for the operator-curated `tokens.yaml` build input.
- [`assets.schema.json`](https://schemas.specify.dev/vectis/assets.schema.json) — JSON Schema for the operator-curated `assets.yaml` build input.

## Retrieving schema bodies

```bash
specify extension schema vectis composition
specify extension schema vectis tokens
specify extension schema vectis assets
```

Each command prints the tool-embedded schema as pretty-printed JSON to stdout.
