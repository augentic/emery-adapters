# Vectis runtime schemas

JSON Schemas (draft 2020-12) for the artifacts the Vectis target consumes and emits. Schemas are owned by the adapter's core crate, which embeds them into the guest that runs the validators; the bodies live under [`core/schemas/`](../core/schemas/). Canonical `$id` URLs:

- [`composition.schema.json`](https://schemas.specify.dev/vectis/composition.schema.json) — JSON Schema for `composition.yaml`. Regenerated by the Vectis target's [`build` prompt](../prompts/build.md); validated by the adapter's deterministic composition validator at the build and merge gates.
- [`tokens.schema.json`](https://schemas.specify.dev/vectis/tokens.schema.json) — JSON Schema for the operator-curated `tokens.yaml` build input.
- [`assets.schema.json`](https://schemas.specify.dev/vectis/assets.schema.json) — JSON Schema for the operator-curated `assets.yaml` build input.

## Retrieving schema bodies

The schema bodies are the committed files embedded in the vectis core crate:

- [`core/schemas/tokens.schema.json`](../core/schemas/tokens.schema.json)
