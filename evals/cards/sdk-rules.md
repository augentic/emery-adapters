## The shared rules

The adapters adopt the SDK's two shared rules (engine `emery-sdk` 0.38 at `33e3665a`, [RELEASES.md](../../RELEASES.md)), giving them what only an adapter can. The first rule is the bound step: a call into the tree whose result is bound (`users = user_list(..)`, `const total = repo.total(id)`) is a `requirement`'s anchor as an awaited call or one made for its effect alone is, unless it constructs — each walker records the SDK's `Use::Bound` for the call an assignment, a declaration, or a `with` item binds, and `python`'s walker now binds `with` targets from their context expressions, so `cur.execute(..)` on a cursor a pool's connection opened traces to the pool's package. The second is the widening's scope: a seam whose modules import what the resolver cannot follow, or load a module by a computed name, lays after its closure the rest of the importing module's package, or of the package the load's literal head spells (`f"app.plugins.{m.name}"`, `plugins.__path__`, `` `./plugins/${name}` ``), in place of the rest of the tree; and an import reaching a test module the keep set aside is `Target::Skipped`, neither unresolved nor followed. The facts the survey turn lays read almost none of this — `--facts` over the sixteen cases against the PR 7 components (the committed tree built `--locked`, its `emery-sdk` at `7ab7abe0`) is byte-identical on fifteen, and `django-styleguide`'s differs by one clause: its unfollowed-imports sentence no longer says `styleguide_example.utils.tests` from `common/factories.py` "names no module of the tree", since the resolver now answers `Skipped` for a test package the keep set aside, and the computed load at `api/mixins.py#L43` is all it names — so the round asks what the two rules do to the extraction turns: the anchors they admit, the files they lay. One graded round per adapter, operator-invoked, three runs under `CURSOR_MODEL` pinned to `composer-2.5`, over the components built from this tree once `make ci` is green; `python` read against `2026-10-01T22-58-28Z` with `2026-10-02T02-37-57Z` and `2026-10-01T22-30-32Z` for `django-styleguide`, `typescript` against `2026-09-29T22-28-34Z` and the cards since.
