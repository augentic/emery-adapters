# Gifting — user stories

The stories the gifting team has agreed for the first release, one directory
per domain. Each story is written as a user, a want, and a reason, followed
by its acceptance list. A story is done when every line of its acceptance
list holds.

- [wishlist/](wishlist/) — the wishlist a member keeps and shares.
- [invoices/](invoices/) — the invoices a seller issues and settles.

Stories are added at the end of the file for their domain; a story that
changes is edited in place, never duplicated.
